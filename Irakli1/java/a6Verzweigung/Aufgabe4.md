# Aufgabe Schaltjahr 
Es soll ein Jahr darauf geprüft werden, ob ein Schaltjahr vorliegt oder nicht

## Variablen
- jahr als ganze Zahl
- istschaltjahr als boolsche Variable

## Bedingungen
- wenn das Jahr durch 4 teilbar ist -> true
- wenn Jahr durch 100 teilbar ist -> false
- wenn Jahr durch 400 teilbar ist -> true
